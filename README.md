# Ascension — Godot/Xogot mobile prototype

Original 2D portrait cultivation idle RPG. Early playable prototype with placeholder UI, not finished anime art.

## Features
- Automatic attacks and increasing enemy stages
- Three manual skills and a charged ultimate
- Four Sword Spirits; two unlocked initially, one equipped at a time
- Qi, Spirit Stones, upgrades and breakthroughs
- Local JSON saves and capped eight-hour offline rewards

## Open on Xogot
From Xogot Projects, select **Download from GitHub** and paste:
https://github.com/MaxwellSick/Ascension

Import the project and press Play. The project file is `project.godot` at repository root.

## Limitations
- Not yet engine-tested on Xogot; share any error screenshot for fixes.
- Placeholder UI; no production sprites or animations yet.
- No purchases, servers, or online accounts.
- One equipped Sword Spirit, not three simultaneously.
- Economy and damage are provisional.
- GitHub version is a compact first implementation and may differ from the earlier ZIP prototype.
